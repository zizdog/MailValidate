# MailValidate

> Typecho 邮箱验证提权插件 — 验证通过后自动提升用户权限

## 简介

MailValidate 是一款 Typecho 博客系统的邮箱验证插件。用户完成邮箱验证后，系统会自动将其用户组从 **subscriber（订阅者）** 提升为 **contributor（贡献者）**，获得发表文章权限（仍需审核）。

适合需要区分注册用户权限、构建多用户社区博客的场景。

## 功能特性

- ✅ **邮箱验证后自动提权** — subscriber → contributor
- ✅ **验证链接带有效期** — 默认 24 小时，过期后需重新发送
- ✅ **发送频率限制** — 默认 60 秒内不可重复发送，防止滥发
- ✅ **安全 Token 生成** — 使用 `random_bytes()` 密码学安全随机，支持 PHP 7+
- ✅ **已验证友好提示** — 已验证用户再次访问链接会提示"已验证"，而非错误页面
- ✅ **邮件模板自定义** — 支持 HTML 邮件模板，内置变量替换
- ✅ **多发送方式** — 支持 SMTP / mail() / sendmail()
- ✅ **后台一键重发** — 后台导航栏直接显示验证/重发按钮
- ✅ **注册即发信** — 新用户注册完成即自动发验证邮件（可关闭）
- ✅ **后台管理面板** — 后台 → 管理 → 邮箱验证：按状态筛选、重发、手动标记、SMTP 自检
- ✅ **发送保护** — 全站每日上限、同 IP 每小时上限、一次性邮箱域名黑名单
- ✅ **发送日志** — 每次发送/验证都有记录（含失败原因），便于排查

## 环境要求

- Typecho 1.2 及以上版本（在 1.3.0 / PHP 8.2 上实测）
- PHP 7.4 及以上（推荐 8.x）
- 如果 SMTP 方式发信，需确保对应端口开放

## 安装方法

### 方式一：手动上传

1. 下载本插件并解压
2. 将 `MailValidate` 文件夹上传至 Typecho 的 `/usr/plugins/` 目录下
3. 登录 Typecho 后台 → 控制台 → 插件 → 找到 **MailValidate** 并启用
4. 点击插件右侧的 **设置**，配置 SMTP 等参数
5. 完成！后台导航栏会出现验证按钮

### 方式二：Git 克隆（推荐开发者）

```bash
cd /path/to/typecho/usr/plugins/
git clone https://github.com/zizdog/MailValidate.git
```

然后在后台启用插件即可。

## 插件配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 发信方式 | SMTP / mail() / sendmail() | SMTP |
| SMTP 地址 | SMTP 服务器地址 | smtp. |
| SMTP 端口 | 服务端口，一般为 25/465/587 | 25 |
| SMTP 用户 | 登录用户名，通常为邮箱地址 | - |
| SMTP 密码 | 登录密码 | - |
| SMTP 验证 | 是否开启认证 / SSL 加密 | 开启认证 |
| 发件人名称 | 邮件中显示的发件人名称 | 博客标题 |
| 邮件标题 | 验证邮件的标题 | 请完成邮箱验证 |
| 发件人邮箱 | From 头里的真实地址；留空则用 SMTP 用户（**SMTP 用户名不是完整邮箱时必填**） | 空 |
| 注册即发信 | 新用户注册完成后自动发验证邮件 | 开 |
| 发送间隔(秒) | 同一用户两次发送的最小间隔 | 60 |
| 验证链接有效期(秒) | 验证链接多久后失效 | 86400（24小时） |
| 同 IP 每小时上限 | 同一 IP 每小时最多触发几封（防批量注册） | 5 |
| 全站每日上限 | 24 小时内全站最多发送几封（保护 SMTP 账号） | 200 |
| 额外拦截的邮箱域名 | 一行一个；子域一并拦截（内置常见一次性邮箱） | 空 |

## 使用说明

### 1. 用户验证流程

1. 用户注册后默认是 **subscriber** 权限
2. 登录后台后，顶部导航栏会显示 **"验证邮件提升权限"** 按钮
3. 点击后系统自动发送验证邮件到用户注册邮箱
4. 用户点击邮件中的 **"立即验证"** 按钮完成验证
5. 系统自动将用户组提升为 **contributor**
6. 用户可发表文章，但需要管理员审核

### 2. 邮件模板自定义

插件目录下有三个模板文件，可自由修改样式：

| 文件 | 用途 |
|------|------|
| `mail.html` | 验证邮件正文模板 |
| `success.html` | 验证成功页面模板 |
| `fail.html` | 验证失败/过期页面模板 |

#### 模板可用变量

所有模板均支持以下变量替换：

| 变量 | 说明 |
|------|------|
| `%sitename%` | 站点名称（博客标题） |
| `%username%` | 用户昵称 |
| `%verifyurl%` | 验证链接地址 |
| `%useravatar%` | 用户邮箱的 MD5 值（用于 Gravatar 头像） |

> **注意**：`mail.html` 支持全部变量，`success.html` 和 `fail.html` 支持 `%sitename%`。

### 3. 重新发送验证邮件

如果用户未收到邮件或链接已过期，可以再次点击后台导航栏的 **"点此重发验证邮件"** 按钮。系统会重新生成验证链接并发送。

### 4. 后台面板

后台 → 管理 → 邮箱验证（`extending.php?panel=MailValidate/panel.php`）：

- 看到所有用户的验证状态、上次发送时间、链接到期时间
- 按「未验证 / 待验证 / 已验证」筛选，按用户名/昵称/邮箱搜索
- 逐个「重发」验证邮件（管理员操作跳过频率限制）
- 「标记已验证」会同时把 subscriber 提为 contributor；「重置」只改状态、不改用户组
- 「发送一封测试邮件给我」用于检查 SMTP 配置
- 底部是最近 40 条发送日志（失败原因在这里看，不在给用户的提示里）

> 日志表 `mailvalidate_log` 在插件启用时自动创建。如果数据库用户没有 `CREATE` 权限，
> 日志与同 IP 限流会降级（不影响发信和验证），面板顶部会提示。

## 常见问题

**Q：启用插件后提示数据库错误？**  
A：请确保插件目录有写入权限，且数据库用户有 `ALTER` 权限。插件会自动在 `users` 表中添加字段，无需手动操作。

**Q：邮件发送失败怎么办？**  
A：检查 SMTP 配置是否正确，特别是端口和加密方式。QQ 邮箱通常使用 `465` 端口并开启 SSL；163 邮箱使用 `25` 或 `465` 端口。

**Q：验证链接点击后提示失败？**  
A：可能是链接已过期（默认 24 小时），请重新发送验证邮件。也可能是 token 已被使用或链接地址被截断。

**Q：已验证用户为什么还能看到验证按钮？**  
A：请确认用户已刷新页面。如果仍显示，请检查数据库中该用户的 `validate_state` 字段是否为 `2`。

**Q：想升级 PHP 8.x，旧版 PHPMailer 兼容吗？**  
A：本插件已内置 PHPMailer 6.9.3，完全兼容 PHP 7.0 - 8.3。
